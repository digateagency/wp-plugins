# Soft Cookie Consent

Плагин cookie-баннера для WordPress.

Показывает посетителю уведомление о cookies и даёт выбрать согласие: принять всё, оставить только необходимые или настроить категории по отдельности (необходимые, функциональные, аналитика, маркетинг).

## Что умеет

- Три варианта размещения: снизу, по центру или в углу (слева / справа)
- Плавное появление баннера с настраиваемой задержкой
- Тексты на русском и английском — всё редактируется в админке
- Настройка цветов, кнопок и внешнего вида
- Ссылка на политику конфиденциальности — выбор страницы сайта
- Можно снова открыть настройки cookies после согласия
- Необязательные скрипты (аналитика, реклама) не запускаются, пока пользователь не согласился
- Поддержка Google Consent Mode v2 для GTM / аналитики

## Установка

Скопируйте папку в `wp-content/plugins/`, активируйте плагин и откройте **Настройки → Soft Cookie Consent**.
